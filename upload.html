Connect to GitHub (one time per device)

This page changes files in your website repository, so it needs a GitHub token that only you have.

How to get a token
  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories → HaoranTang.github.io.
  3. Permissions: Repository permissions → Contents → Read and write. Nothing else is needed.
  4. Choose an expiration (for example 1 year), then Generate token and copy it.
